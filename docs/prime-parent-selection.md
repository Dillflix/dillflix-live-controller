# Multiple Prime event tiles

A search can return multiple parent tiles for the same sporting event. Their
broadcast lists are not interchangeable. Both catalogue preflight and direct
executor requests now use the same selection loop:

1. Match a parent against the requested event and permitted viewing options using
   the existing identity matcher.
2. Inspect its broadcasts and apply per-broadcast entitlement, live state,
   language and route checks.
3. Stop on an entitled LIVE English or unlabeled feed. Otherwise remove only that
   parent from the working candidate set and match the remaining search results.
4. If no playable feed is found, retain uncertainty from any failed, malformed,
   paginated or ambiguous alternative. Otherwise prefer an upcoming entitled feed
   over a locked or unavailable outcome.

French and other explicitly non-English feeds remain excluded under the configured
deployment policy. An entitled French feed does not become a locked feed; it is
ineligible by language. The locked outcome's user-facing message refers to
English/unlabeled feeds on the inspected routes, not account-wide entitlement.

The original search response is preserved. Diagnostic `parent_selections` records
each matched parent, matching evidence, broadcast candidates, selected child,
outcome and inspection error. It is included in catalogue activity so a later
probe does not erase the selection chain from the incident history. Progress is
recorded before asynchronous matching/inspection; a timeout or cancellation keeps
the partial record and cannot authorize a definitive catalogue exclusion.

The scan considers the supplied search results; it does not add search pagination.
Existing overall deadlines and result-freshness limits still apply. Session,
runtime generation, ownership, manual control and intent checks remain enforced.
A retryable broadcast inspection error permits checking another matched parent;
a session/ownership change stops the scan. Every alternative must independently
pass event matching; an unrelated search tile is never tried as a fallback.

Catalogue contract 13 clears exclusions generated by the old single-parent policy
when the controller starts. Watch plans and verified playback are preserved;
normal scheduling rechecks eligible events with fresh catalogue evidence.
